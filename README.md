# ODE_solver_comparison
A practical benchmark comparing traditional Python scientific computing (scipy) against modern differentiable programming (JAX, diffrax, optax) for solving ODEs and optimizing cosmological inference.
# TDS Article Figures: "My scipy ODE solver was killing my Bayesian inference"

This repository contains the full code used to generate the benchmarking figures for the Towards Data Science (TDS) article: **"My scipy ODE solver was killing my Bayesian inference"**.

The code provides a performance and workflow comparison between traditional Python scientific computing (`scipy.integrate.solve_ivp`, finite difference gradients) and modern differentiable programming ecosystems (`JAX`, `diffrax`, `optax`). 

The context is a mock cosmological inference problem: estimating the matter density $\Omega_m$ and the Hubble constant $H_0$ for a flat $\Lambda$CDM universe by integrating the Hubble expansion and comparing the results to mock Supernovae Type Ia (SNIa) distance moduli data.

## 📁 Repository Contents

- `TDS_fig.py`: The main Python script. It contains the mock data generation, forward model definitions, benchmarking logic, gradient calculations, full MAP inference routines, and figure plotting code.
- `tds_summary.json`: A JSON output containing the key numerical statistics and timing results from the benchmarks.
- `tds_fig1_horror.pdf` — `tds_fig5_gotchas.pdf`: The output PDF figures generated by the script.

## 📊 Generated Figures

1. **`tds_fig1_horror.pdf`**: Visualizes the dramatic timing bottleneck (the "horror") when running 100,000 likelihood calls in an MCMC/Nested Sampling run like `dynesty`, comparing the scipy pipeline to the diffrax pipeline.
2. **`tds_fig2_speedup.pdf`**: Shows the raw single-call speedup of the forward model evaluating comoving distance (Diffrax vs. `solve_ivp`), alongside a plot of the mock SNIa inference problem.
3. **`tds_fig3_gradient.pdf`**: Compares the cost of one gradient step between central finite difference (which scales linearly with parameter count) and JAX autodiff (constant cost), overlaying a gradient vector on the loss landscape.
4. **`tds_fig4_inference.pdf`**: A full optimization/inference comparison. It tracks the convergence of $\Omega_m$ and $H_0$ and the likelihood loss over 350 iterations between `scipy` + Gradient Descent and `diffrax` + `optax` Adam.
5. **`tds_fig5_gotchas.pdf`**: A visual summary of three common pitfalls when transitioning to JAX and Diffrax:
    - **Gotcha 1:** Forgetting to enable 64-bit precision (`jax_enable_x64`).
    - **Gotcha 2:** Benchmarking without warming up JIT compilation.
    - **Gotcha 3:** Misinterpreting RHS function argument orders (e.g., `solve_ivp`/`diffrax` expecting `(t, y, args)` while `scipy.integrate.odeint` uses `(y, t, args)`).

## 🚀 How to Run

### Prerequisites
Make sure you have the required dependencies installed:
```bash
pip install jax jaxlib diffrax optax scipy numpy matplotlib
```

### Running the script
To run the benchmarks and regenerate all figures and the JSON summary, simply execute:
```bash
python TDS_fig.py
```
*Note: Depending on your hardware, running the full script and compiling JAX functions will take a few seconds.*
